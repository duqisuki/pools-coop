## English

Unofficial co-op mod for POOLS (Steam). Run **`install.bat`** from the downloaded repository (it finds the game in your Steam library,
downloads the pinned BepInEx 6 IL2CPP build with a SHA-256 check and copies it plus `PoolsCoop.dll` next to `POOLS.exe`), start the game,
press **F7** in the main menu: *Host a game* or *Join a friend*. Both players need the mod, must be Steam friends, and start the same chapter.
`uninstall.bat` removes exactly what was installed; saves are never touched. Tested with bots on two game copies and one Steam account only;
not yet with a second real person or a headset. No game files are included. MIT licence for the mod code; BepInEx is downloaded
separately under its own licence.
